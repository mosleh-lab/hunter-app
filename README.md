# نظام الصياد

تطبيق على طريقة سولو ليفلنج للحياة اليومية: مهام يومية وخبرة ومستويات ورتب وعقوبات.

- **يومي:** الصلوات الخمس، ورد القرآن، التسبيح والأذكار، الخطوات، الأكل النظيف والسعرات والبروتين، النوم، الدوام، النادي، تطوير الذات، ومهام خاصة فيك.
- **أسبوعي:** هدف النادي.
- **شهري:** الادخار والاستثمار والدخل الإضافي، والأهداف تحددها من داخل التطبيق.

كل البيانات تنحفظ على جهازك فقط، ولا ترتفع لأي سيرفر.

## التثبيت على الجوال

افتح الرابط على جوالك:
- **آيفون:** من Safari اضغط زر المشاركة، واختر "إضافة إلى الشاشة الرئيسية".
- **أندرويد:** من Chrome اضغط ⋮ واختر "تثبيت التطبيق".
